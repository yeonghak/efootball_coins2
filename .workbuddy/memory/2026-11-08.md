## 攒币助手小程序：数据模型改为「余额快照」+ 记录删除（需求变更，已完成）

### 需求
1. 不再区分「获得 / 消费」，每天记录的是**游戏账户当前金币总额**
2. 用户可以删除自己任意一条记录

### 模型变更（v1 流水 → v2 快照）
```js
// v1: { id, date, type:'gain'|'spend', amount, source, note, createdAt }
// v2: { id, date, balance, note, createdAt }   // 一天最多一条
```
- `getCurrentCoins` 从「初始 + 累加」改为「取最新快照的 balance」，无记录时回落 `startingCoins`
- 新增 `getBaseline(data, key)`（该日之前最近一次余额）、`getChangeOn`（当日变化）、`getNetBetween`、`getMonthNet`、`getRecordsInMonth`
- 新增 `upsertDayBalance`（同一天覆盖，保证一天一条）、`removeRecord`、`removeRecordOn`
- 删除 `addRecord` / `getDailyNet` / `setDailyNet`（净额调整概念整体废弃）
- **自动迁移**：`looksLegacy()` 检测到 `amount/type` 字段时，按 `createdAt` 正序累加成余额，再把同一天合并为一条快照，迁移后回写。存储 key 仍是 `efootball_coins_data_v1`（避免老数据失联），内部 `version: 2`
- 默认数据同步改成快照：昨天 2670、今天 2750（与原 2520+150+80 完全一致）

### 页面改动
- **record.vue**：删除获得/消费切换与来源选择器；输入「当前账户金币总额」，预填今日已有记录或当前余额；实时显示「比上次 ±N」；保存走 `upsertDayBalance`
- **index.vue**：最近记录改为「日期 + 备注 / 余额 + 变化」，不再有正负号语义；查看全部 → 历史页
- **calendar.vue**：格子显示**当天变化**（由快照链推导），无记录显示 `—` 且淡色底；编辑区改为输入「当天账户总额」，并提示「上次 X 月 X 日 · 余额」；新增「删除这天记录」
- **stats.vue**：柱状图改为每日变化；「获得/消费」指标删除，改为「记录天数 / 日均增长」
- **profile.vue**：新增「全部记录」入口
- **history.vue（新增页面）**：全量记录列表，每行显示日期/备注、余额、变化，右侧「删除」按钮二次确认；已注册 `pages/history/history`
